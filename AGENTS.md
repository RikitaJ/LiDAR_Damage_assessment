# Agent instructions

Before any work in this repo, read and follow:

1. `docs/ASSESSMENT_BRIEF.md`: the single source of truth. Read all of it at the start of every session.
2. `docs/GIT_PROTOCOL.md`: pull before you start, then commit and push after every change that works.
3. `docs/HANDOFF.md`: open items and answers between Builder and Tester. Check it after every pull.
