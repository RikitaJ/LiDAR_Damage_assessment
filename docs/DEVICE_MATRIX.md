# Device matrix

Which input tier runs on which iPhone, and what accuracy each tier has actually shown. Every capture we made came from one iPhone 13 Pro running iOS 18.7.8, so every other cell is untested.

| Device | LiDAR tier (Stray Scanner) | Photo tier (Camera app) | Video tier (Camera app) |
|---|---|---|---|
| iPhone 13 Pro, iOS 18.7.8 (our only device) | Measured on room B1 (table below). In spec: the brief asks for a Pro-class device. | Runs; accuracy not measured. With iPhone HEIC photos the tier can't read the EXIF intrinsics and falls back to a prior; JPEG ("Most Compatible") is untested. A deviation: the brief asks for iPhone 15 or newer. | Runs; accuracy not measured. A plain iPhone video has no metric scale yet. A deviation: the brief asks for iPhone 15 or newer. |
| iPhone 15 Pro / 16 Pro (and Pro Max) | Expected to run; Stray Scanner needs iOS 18.6 or later. Not tested. | Not tested. | Not tested. |
| iPhone 15 / 16 (and Plus) | Not available: no LiDAR sensor. | Not tested. | Not tested. |

The pipeline reads intrinsics from the capture files (`camera_matrix.csv` and `odometry.csv` for LiDAR, EXIF for photos). It records the device model but never branches on it.
